## 2. Research Goals & Objectives
1. Construct a comprehensive, open computational dataset covering Bangladeshi music development from 1972 to present.
2. Formulate the Bangladesh Musical Ecosystem Model (BMEM) and Bangladesh Music Evolution Framework (BMEF).
3. Analyze multi-layer co-appearance networks, influence citations, and genre strand genealogies across metal, rock, folk-fusion, hip-hop, and pop.
4. Provide interactive exploration tools via a Next.js / TypeScript web application.

## 3. Technology Stack & Constraints
- **Data & Analytics:** Python, NetworkX, Pandas, NumPy, Louvain modularity algorithms.
- **Web Interface:** Next.js (App Router), TypeScript, Tailwind CSS, Vercel deployment.
- **Documentation:** Markdown (GFM), SVG visualizations, empirical CSV/JSON outputs.
